# B7store front-end
Aplicação web simulando uma loja de roupas com STRIPE

## 🚀 Tecnologias Utilizadas
- NextJS
- TailwindCSS
- Typescript
- Zustand

## 📦 Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina as seguintes ferramentas:
- [Git](https://git-scm.com)
- [Node.js](https://nodejs.org/) (versão recomendada: 18+)
- Um gerenciador de pacotes: [npm](https://www.npmjs.com/) ou [yarn](https://yarnpkg.com/)

## 🔧 Como rodar o projeto
1. Clone o repositório:
bash
git clone https://github.com/DaviMostaro/b7store-frontend.git


2. Entre na pasta do projeto:
bash
cd b7store-frontend


3. Instale as dependências:
bash
npm install
# ou
yarn install


4. Clone e roda o backend na sua máquina: https://github.com/DaviMostaro/b7store-backend


5. Execute o projeto:
bash
npm run dev
# ou
yarn dev


6. Acesse no navegador:

http://localhost:3000



## ✅ Funcionalidades
- [x] Funcionalidade 1 – Store via zustand para gerenciar carrinho e login
